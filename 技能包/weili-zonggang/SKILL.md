## 核心判断

### 韦千里体系三大根本原则

**原则一：以日干强弱为一切断法之起点**

评断八步中，第一步就是"看强弱"。强弱判断标准：

| 等级 | 条件 |
|------|------|
| 最强 | 既当令又多帮扶 |
| 中强 | 仅多帮扶而失令，或仅得令而少帮扶 |
| 次强 | 既不当令又少帮扶，但支得气 |
| 最弱 | 既失令又多克泄 |
| 中弱 | 仅多克泄而当令，或仅失令而少克泄 |
| 次弱 | 不失令少克泄，但支无气 |

**原则二：用神即"助强扶弱"之神（与子平真诠的根本分歧）**

- 身强→抑之（克泄耗：官杀克、食伤泄、财耗）
- 身弱→扶之（生扶比：印生、比劫助）
- 用神七要：有势有力、有援助、在干得气、在支不见克合、在支得干生助、在支无刑冲合害、既见冲克而有解救。
- 用神之区别：健全（无克合刑冲）、相神（生助或解救用神之字）、格局相兼（格局即用神）。

**原则三：六亲更定——印为父（非偏财为父）**

韦千里引自《命理约言》，彻底推翻传统。父：男女命皆以印为父；母：同父；夫：官杀；妻：财；兄弟：比劫；子：食伤（男女同）。
