# 韦千里 · 八字分析技能包

基于民国命理大师韦千里《千里命稿》与《八字提要》蒸馏而成的 AI 八字分析技能包（9 个技能）。

把韦千里的评断八步法、格局体系、用神取法、六亲更定（印为父）、行运折衷法、独家误区纠正等断法规则，从原著中结构化提取为可直接被 AI 调用的 SKILL.md 技能。结论来自古籍规则匹配，用于命理研究与内容创作参考。

## 韦千里体系三大特色

1. **印为父**：引自《命理约言》，彻底推翻"偏财为父"的传统，男女命皆以印为父。
2. **用神=助强扶弱**：与子平真诠的格局用神有根本分歧，韦千里以日干强弱为一切断法之起点。
3. **行运折衷法**：前五年天干七分兼看地支三分，后五年地支七分兼看天干三分。

## 安装

1. 打开你的 AI 助手的「技能 / 插件 / Skills」入口。
2. 点「导入 / Import」，选中 技能包/ 里的某一个技能文件夹。
3. 导入后启用即可。每个技能是一个独立文件夹，里面只有一个 SKILL.md。

## 使用示例

给助手一个八字排盘（年柱 月柱 日柱 时柱 性别），然后问：

`
帮我看这个八字：甲子 乙亥 庚戌 癸未 男
`

助手会自动触发韦千里技能包，按评断八步程序分析。
